# Photography Portfolio — IKUNORI NAKAGAWA

HTML / CSS / JavaScriptのみの静的サイトです。ビルドや外部ライブラリ、APIキー、外部フォントは不要です。

## プレビュー

`index.html`をブラウザで開きます。スマートフォンの確認には、フォルダを静的Webサーバーから配信してください。

## GitHub Pagesで公開

1. このフォルダの**中身**をGitHubリポジトリのルートにアップロードします。`assets`を含むすべてのファイルが必要です。
2. リポジトリの Settings → Pages → Build and deployment で「Deploy from a branch」を選択します。
3. 使用するブランチと `/ (root)` を選択し保存します。
4. GitHubが表示する公開URLを開きます。

すべて相対パスなので、プロジェクト用Pagesのサブディレクトリでも利用できます。Netlifyなどの静的ホスティングにもそのまま配置できます。

## 内容と更新

- `index.html`：プロフィール、連絡先、ページ構成
- `style.css`：色、レイアウト、画面幅ごとの調整、動きの抑制
- `script.js`：カテゴリ絞り込み、ライトボックス、キーボード・スワイプ操作、追従ナビ
- `data.js`：写真と撮影情報。ローカルファイルでも読み込める形式です
- `assets/images`：PDFの全46画像をWebPへ変換。最大2000px版と最大800px版
- `assets/photo-manifest.json`：元PDFのページ番号と各画像・情報の対応

ギャラリーには作品写真41点を表示します。表紙、プロフィール、SELECTED WORKの2点、THANK YOUの計5点は、元PDFの構成に対応する素材として別途保持しています。SELECTED WORKの2点も画像フォルダに保存済みです。

PDFに残っていた「PHOTO A」「Location」「Short series title」等のテンプレート文言は掲載していません。プロフィール文は意味を保ってWeb向けに整え、メールアドレスのPDF抽出時の余分な空白を除去しました。ページ4は上野公園の桜シリーズとして整理しました。

レンズ・露出設定はPDFの各代表写真（5・10・15・18ページ）に記載されたものだけを対応する写真に表示しています。同シリーズの別写真へ設定を転記していません。日付・場所はシリーズの情報です。PDFの「公開終了」の記述は現況を断定しない撮影体験の説明に整えています。

動きを減らすOS設定に対応しています。ライトボックスは左右キー・Esc・スワイプで操作できます。公開前に撮影対象の掲載許諾と連絡先をご自身でご確認ください。
